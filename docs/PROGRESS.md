## Этап 6: что реально работает (проверено тестами и в браузере)

- Вход `/admin/login`, выбор студии, учётная запись (смена пароля, выход остальных устройств), меню «Ещё» для телефона.
- Главная `/admin/{id}/`: KPI, таймлайн боксов, список дня, новые заявки с «Подтвердить», ближайшие дни, статистика неделя/месяц/квартал.
- Записи `/admin/{id}/bookings`: неделя, день по боксам, список с поиском; панель редактирования (статус, данные, перенос, отмена); создание записи с подсказкой свободного времени; карточка записи для телефона.
- Клиенты `/admin/{id}/clients`: поиск, сегменты, карточка, история, правка, добавление, «Записать снова».
- Услуги `/admin/{id}/services`: прайс по разделам, переключатель онлайн-записи, порядок, панель редактирования (фото из медиатеки, мастера, длительность), вкладки «Направления на сайте» (тексты карточек и страниц, галерея) и «Разделы прайса».
- API: медиатека (`app/api/routes/admin_media.py`), каталог (`admin_catalog.py`), клиенты (создание), смена пароля.
