## Этап 6: проверено тестами и в браузере

- Все экраны админки на 1440 и 390 px без горизонтальной прокрутки и ошибок JS.
- Тест-правило приёмки: изменение каждого блока главной через API видно на сайте (`tests/api/test_admin_content.py`).
- Сценарии в браузере: правка и создание записей, услуги (фото, мастера, порядок), график мастера, особые дни,
  блокировки, правила слотов, медиатека, редактирование блоков со списками, доступ с временным паролем.

## Известные проблемы

- В локальной dev-базе есть тестовые записи 1001-1009 и правки от ручных проверок (только локальный Docker volume, не продакшен).
- Счётчики rate limit в памяти процесса: верно для одного `api`, для нескольких реплик нужен Redis.
- Мини-приложение Telegram и Secure-cookie работают только по HTTPS: появятся после выкладки (этап 9).
