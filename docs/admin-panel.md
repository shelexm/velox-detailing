# Панель студии

Адрес: `/admin`. Публичной регистрации нет.

## Первый вход

1. Первый владелец создаётся командой на сервере (пароль вводится интерактивно и нигде не печатается):
   `docker compose run --rm api python -m app.cli create-admin --email owner@example.com --name "Имя"`
2. Остальных сотрудников владелец добавляет в разделе «Доступ». Новому аккаунту выдаётся временный пароль:
   он показывается один раз, хранится только хешем. Сотрудник меняет его в «Учётной записи».
3. Забытый пароль сотрудника сбрасывает владелец («Доступ», «Сбросить пароль»); пароль владельца сбрасывается
   той же командой `create-admin` с флагом `--reset-password`.

## Роли

| Роль | Что видит и меняет |
|---|---|
| Владелец | всё, включая «Настройки» (контакты, реквизиты, бот) и «Доступ» |
| Администратор | записи, клиентов, услуги, мастеров, расписание, слоты, контент сайта, медиатеку |
| Мастер | главную и календарь только со своими записями, без правки |

Сотрудник с доступом к нескольким студиям после входа выбирает студию.

## Разделы

- **Главная:** записи сегодня, таймлайн боксов, новые заявки (подтвердить или позвонить), ближайшие дни, статистика.
- **Записи:** неделя, день по боксам, список с поиском; правка, перенос, смена статуса, отмена, новая запись по звонку.
- **Расписание:** часы и перерывы по дням недели, особые дни (выходной или сокращённый), блокировки времени, графики мастеров.
- **Услуги:** прайс по разделам, цена, длительность, мастера, фото, онлайн-запись; направления (карточки и страницы
  «Подробнее» на сайте), разделы прайса.
- **Мастера:** профиль, услуги, личный график внутри часов студии, отпуска и больничные, загрузка недели.
- **Слоты:** шаг сетки, число мест (боксов), буфер, срок записи, горизонт, учёт занятости мастеров, предпросмотр
  сетки так, как её видит клиент.
- **Клиенты:** поиск, сегменты, карточка с историей, заметки и метки, «Записать снова».
- **Контент сайта:** каждый блок главной страницы (тексты, списки, фото), видимость и порядок блоков, сертификаты.
- **Медиатека:** загрузка (JPG, PNG, WebP, AVIF до 5 МБ, метаданные удаляются), описание alt, автор и лицензия,
  замена файла без потери мест на сайте, удаление только неиспользуемых фото.
- **До и после**, **Отзывы:** пары фото и отзывы с публикацией, порядком и метками «Примеры работ» и «ДЕМО».
- **Настройки:** контакты, адрес, маршрут, WhatsApp, Telegram-бот, реквизиты. Пустые поля на сайте не показываются.

## Безопасность

Сессия в HttpOnly-cookie, каждое изменение с CSRF-токеном, лимит попыток входа, страницы `/admin` закрыты от
поисковиков (`noindex`, `no-store`). Подробности: `docs/security.md`.
