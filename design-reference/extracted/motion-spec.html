02 · Блик по лаку

РАБОТАЕТ В МАКЕТЕ

Мягкая полоса шириной ~18 % кадра под углом 105° проходит слева направо за 4,2 с, затем пауза. В макете она идёт по всему кадру; в разработке — по маске кузова (альфа-канал рендера или короткое видео 6 с, WebM/MP4 ≤ 1,5 МБ), чтобы свет скользил только по лаку.

Три слоя первого экрана движутся с разной скоростью только пока экран виден: смещение автомобиля — не больше 80 px. Реализация: transform: translate3d по requestAnimationFrame или ScrollTimeline; без scroll-jacking и без инерционной прокрутки.

05 · Микровзаимодействия

В МАКЕТЕ
Наклон карточек
Наведение: до 6°, фото 105 %, рамка — золото. В макете — фиксированный наклон; слежение за курсором — в разработке.
В МАКЕТЕ
Ползунок «До / После»
Перетаскивание мышью и пальцем, клавиши ← → шагом 5 %. Смена кейса — плавная смена кадров 450 мс.
РАЗРАБОТКА
Подсказка у ползунка
При первом показе ручка один раз качается 50 → 42 → 58 → 50 % за 1,6 с. Увеличение фото — по нажатию, просмотр на весь экран.
РАЗРАБОТКА
Появление секций
IntersectionObserver на 15 % видимости, один раз: текст — сдвиг 24 px и прозрачность, фото — раскрытие снизу и масштаб 1,06 → 1.
Пример появления блока при прокрутке — в макете проигрывается по кругу только для наглядности. На сайте — один раз.
ЗАПИСАТЬСЯ
Кнопки: при наведении по золоту проходит тот же блик (600 мс), стрелка у ссылок смещается на 4 px. Нажатие — масштаб 0,98.
